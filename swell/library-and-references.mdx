During a Swell conversation, you can pull in assets from your workspace image library or design references without leaving the chat. An interactive picker appears inside the conversation, letting you choose exactly which image or reference to work with. What you select becomes part of the context for the current draft.

## Opening the image library picker

Ask Swell to use an image from your library — for example, *"use an image from my library"* — or click the attachment icon and choose the library option. An interactive picker will open showing the images available in your workspace. Select the image you want and it is added to the conversation as context for the current draft.

## Opening the references picker

Ask Swell to apply a specific design reference or style — for example, *"apply the spring campaign reference"* or *"use my brand style guide"*. Swell will open the references picker so you can select the relevant reference. Once selected, Swell applies its style and guidelines to the current draft.

## Session context vs. workspace settings

Selecting an asset through the picker and editing your workspace settings have different scopes:

<Tabs>
  <Tab title="Selecting in the picker">
    The chosen image or reference applies **to the current draft only**. It does not change what Swell uses in future conversations or for other campaigns in this workspace. Use this when you want one-off creative direction.
  </Tab>
  <Tab title="Editing workspace References">
    Changes to workspace References **permanently update what Swell uses for all future drafts** in this workspace. Every new conversation in this workspace will draw on the updated references. Use this when you want a style or asset to become a standing brand rule.
  </Tab>
</Tabs>

<Note>
  If you find yourself selecting the same image or reference in every conversation, add it to your workspace References instead. Swell will apply it automatically from then on, keeping your drafts consistently on-brand without extra steps each session.
</Note>
