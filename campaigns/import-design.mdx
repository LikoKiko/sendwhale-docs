If you already have an email design — whether it is an HTML file, a screenshot of a previous campaign, or a Figma layout — you can import it into SendWhale as a starting point rather than building from scratch. After importing, the campaign opens in the editor for further refinement before you send.

## Import options

<Tabs>
  <Tab title="HTML paste">
    Paste raw HTML email code directly into the import dialog. SendWhale accepts standard HTML email markup and opens it in the code view. You can then edit the HTML directly or, for block-based sections, switch to the visual editor.

    **Things to check after HTML import:**
    - Image `src` URLs resolve to publicly accessible images
    - All links point to the correct destinations
    - The layout renders correctly on mobile widths
    - The footer contains the required unsubscribe link and business address (SendWhale adds these automatically if missing)
  </Tab>
  <Tab title="Screenshot">
    Upload a screenshot of an existing email — for example, a PNG or JPEG exported from your email client. Swell analyzes the screenshot and recreates the layout as an editable campaign using block-based components.

    Because Swell is interpreting a visual image, the recreated layout is an approximation. Review every section after import for accuracy.
  </Tab>
  <Tab title="Figma">
    Import a design directly from Figma.

    <Info>
      Figma import may require additional setup or integration configuration. Check [Settings](/settings) in your workspace to confirm availability for your account.
    </Info>
  </Tab>
  <Tab title="Swell AI">
    Ask Swell to generate a complete email design based on a description of your campaign goal, brand, or content. The generated design opens in the editor as a fully editable campaign.
  </Tab>
</Tabs>

## Editable blocks vs. full HTML

Depending on how you import, your campaign will be in one of two editing modes:

| Mode | When it applies | How to edit |
|---|---|---|
| **Block-based** | Designs imported as templates or generated by Swell | Drag-and-drop editor + code view |
| **Full HTML** | Designs imported via HTML paste | Code view only |

If you import raw HTML and later want drag-and-drop editing, you will need to rebuild the layout using blocks in the visual editor.

## Review checklist after importing

Before you send an imported design, work through this checklist:

<Steps>
  <Step title="Check image URLs">
    Confirm every image in the campaign loads from a publicly accessible URL. Broken images appear as blank spaces in the inbox.
  </Step>
  <Step title="Add alt text">
    Add descriptive alt text to every image. Many recipients read emails with images disabled.
  </Step>
  <Step title="Verify all links">
    Click through every button and text link in the preview to confirm they point to the correct destinations.
  </Step>
  <Step title="Preview on mobile">
    Switch to mobile preview in the editor toolbar. Multi-column layouts often need adjustments to stack correctly on small screens.
  </Step>
  <Step title="Check email-client rendering">
    Send a test email to yourself and open it in the email clients your audience uses — particularly Outlook, Gmail, and Apple Mail.
  </Step>
</Steps>

<Note>
Always review imported designs for broken images, missing alt text, incorrect links, and mobile readability before sending. What renders correctly in a browser may not render correctly in every email client.
</Note>
