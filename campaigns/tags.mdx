The Tags page at [/app/tags](https://www.gosendwhale.com/app/tags) is where you create and manage the labels you use to organize your campaigns. Tags give you a fast way to filter and group campaigns in your campaign list — whether by project, client, channel, content type, or any other category that makes sense for your team.

## Creating a tag

<Steps>
  <Step title="Open the Tags page">
    Navigate to [/app/tags](https://www.gosendwhale.com/app/tags).
  </Step>
  <Step title="Create a new tag">
    Select **New Tag** and give it a name — something clear enough to recognize in a filter list.
  </Step>
  <Step title="Choose a color">
    Pick a color for the tag. Colors make tags visually distinct in the campaign list and are especially useful when you have many tags.
  </Step>
  <Step title="Save">
    Confirm to create the tag. It is now available to apply to any campaign in your workspace.
  </Step>
</Steps>

## Applying tags to campaigns

Apply a tag from the campaign list or from within a campaign's settings. You can apply multiple tags to a single campaign. Once applied, you can filter your campaign list by tag to show only campaigns with that label.

## Renaming a tag

To rename a tag, open the Tags page, select the tag, and enter a new name. The updated name applies everywhere the tag is used — across your campaign list, filters, and any reports that reference the tag. No reassignment is needed.

## Removing a tag

To delete a tag:

1. Open the Tags page
2. Select the tag you want to remove
3. Choose **Delete**
4. Confirm the deletion

Deleting a tag removes it from every campaign it is currently applied to. Review the usage count shown next to the tag before deleting — if the count is high, removing the tag may affect how your team filters and finds campaigns.

## Usage counts

The Tags page shows a usage count next to each tag — the number of campaigns that currently have that tag applied. Use usage counts to identify tags that are heavily in use (and should be renamed carefully) versus tags that are unused (and may be safe to remove).

## Searching tags

Use the search field on the Tags page to filter the tag list by name. This is useful when you have a large number of tags and need to find a specific one quickly.

<Note>
Campaign tags are for organizing your campaigns. Contact tags — used in audience segmentation conditions and automation filters — are separate and managed on the Contacts page. Adding a tag to a campaign does not affect your contacts, and adding a tag to a contact does not apply it to any campaigns.
</Note>
