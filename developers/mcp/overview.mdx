The SendWhale MCP server is a local stdio server built on the official TypeScript MCP SDK, with a Deno entry point at `mcp/stdio.ts`. It runs entirely on your own machine — there is no hosted service, no remote connector, and no installation through an MCP marketplace. Your AI client launches the Deno process directly, and all operations run against your SendWhale account using your user JWT and workspace ID.

## What the MCP server enables

Once connected, your AI client can:

- Read your workspace brand context, memories, and design instructions
- List and retrieve campaigns, templates, and audiences
- Create campaign drafts and email templates
- Manage audiences and save images to your workspace library
- Store durable brand facts and update brand instructions

<Info>
The MCP server never sends or schedules campaigns. Delivery always requires a final human review step in SendWhale's authenticated UI.
</Info>

## Supported clients

The MCP server works with any AI client that can launch a local stdio process and speaks the MCP protocol.

<Warning>
There is no remote ChatGPT connector or MCP marketplace listing for SendWhale. The server runs locally on your machine — it is not a hosted HTTP or SSE service.
</Warning>

## How it works

1. Your AI client reads your MCP config and launches the Deno process, passing environment variables that include your user JWT and workspace ID.
2. The MCP server starts up, validates your credentials, and confirms you have access to the specified workspace.
3. Your AI client discovers the available tools, resources, and prompts exposed by the server.
4. When you invoke a tool or resource, the server authenticates the request against your SendWhale account and returns structured results.
