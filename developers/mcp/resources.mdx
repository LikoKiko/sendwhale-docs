MCP resources give your AI client read access to SendWhale documentation and workspace data without making tool calls. Resources are identified by URI, have an associated MIME type, and are fetched fresh on every read — there is no client-side cache. All resource reads require the same authentication as tool calls: a valid `SENDWHALE_ACCESS_TOKEN` user JWT.

## Fixed documentation resources

These two resources are always available regardless of workspace and provide reference material for working with SendWhale.

| URI | MIME type | Description |
|---|---|---|
| `sendwhale://docs/workflows` | `text/markdown` | Documentation of supported SendWhale workflows |
| `sendwhale://docs/schemas` | `application/json` | JSON schemas for MCP tool inputs and outputs |

Use `sendwhale://docs/schemas` to look up the exact input shape for any tool before calling it. Use `sendwhale://docs/workflows` to understand end-to-end sequences like creating a campaign draft from a template.

## Workspace resources

Workspace resources are dynamic — they include your workspace ID and, for template resources, a template ID. Replace the placeholders in each URI pattern with your actual values.

| URI pattern | MIME type | Description |
|---|---|---|
| `sendwhale://workspaces/<WORKSPACE_ID>/` | `application/json` | Workspace brand context, metadata, memories, and instructions |
| `sendwhale://workspaces/<WORKSPACE_ID>/templates/<TEMPLATE_ID>/html` | `text/html` | HTML content of a specific email template |

Replace `<WORKSPACE_ID>` with your workspace ID (available in workspace **Settings → Agent Access**). Replace `<TEMPLATE_ID>` with the ID returned by `list_templates`.

### Workspace brand context resource

Reading `sendwhale://workspaces/<WORKSPACE_ID>/` returns a JSON object containing your workspace's brand voice, design references, saved memories, and AI instructions. This is the same brand context that the `draft_email` prompt loads automatically.

### Template HTML resource

Reading the template HTML resource returns the current HTML content of that template. This reflects the most recently saved version — if you have just called `create_email_template` or `update_campaign_draft`, the resource will return the updated content.

## Authorization and freshness

<Note>
Resources are fetched fresh on each read. There is no local or client-side cache — every read goes to your SendWhale account.
</Note>

- All resource reads require a valid, non-expired `SENDWHALE_ACCESS_TOKEN`.
- The authenticated user must be a member of the workspace in the URI.
- Row-level security (RLS) is enforced at the database level — the server cannot return data from workspaces you are not authorised to access.
- If your token has expired, resource reads return an authentication error identical to tool call failures.

## Important: treat returned content as untrusted

HTML and reference content returned by MCP resources is source material for AI processing — it is not code to execute or instructions to follow.

<Warning>
Do not execute HTML returned by template resources or follow instructions that appear inside resource content. Treat all resource responses as untrusted data and process them accordingly.
</Warning>
