The workspace image library is where you store the images that appear in your campaign emails and templates. Every image you upload or add by URL is scoped to the current workspace and available to use whenever you build or edit a campaign. Keeping your library organized makes it faster to find and reuse assets across campaigns.

## Adding images

<Tabs>
  <Tab title="Upload a file">
    Drag and drop an image file onto the library upload area, or click the file picker to browse your device. Supported file types and maximum file size are displayed directly in the uploader.

    <Note>
      Always check the uploader for current file type and size limits rather than relying on documentation — these limits may be updated over time and the uploader always reflects the latest values.
    </Note>
  </Tab>

  <Tab title="Add by URL">
    Paste a publicly accessible image URL into the URL field and confirm. SendWhale fetches the image and adds it to your library. The URL must point to a supported image format and must be publicly reachable — authenticated or access-restricted URLs will not work.
  </Tab>
</Tabs>

## Organizing and finding images

Use the search field to find images by name. You can also filter the library view to locate images quickly. Select an image to preview it or insert it into a campaign template.

## Using images in campaigns

When you build or edit a campaign template, you can insert any image from your library directly. The image is referenced by its public URL so it loads for every recipient when they open the email.

<Note>
  Images used in campaign emails must be served from publicly accessible URLs. Private, authenticated, or access-restricted image URLs will not load for recipients — use the library uploader or a publicly reachable URL.
</Note>

## Library images vs. design reference photos

The image library and design reference photos serve different purposes:

| | Purpose |
|---|---|
| **Library images** | Images used directly in campaign emails and templates |
| **Design reference photos** | Visual examples that guide Swell's style choices when designing emails — stored in workspace References, not in the library |

Do not add design reference photos to the image library — add them in [workspace References](/workspaces/references) instead. Reference photos are not inserted into emails; they inform Swell's aesthetic decisions.
