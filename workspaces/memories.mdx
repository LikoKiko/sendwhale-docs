Memories are durable facts about your brand that Swell stores and recalls automatically when drafting emails for your workspace. Unlike a note you type into a chat session, a memory persists across every conversation and every campaign — Swell draws on it without you needing to repeat yourself. Use memories to encode stable truths about your brand: your core products, tone preferences, audience characteristics, and anything else Swell should always keep in mind.

## What to store as memories

<CardGroup cols={2}>
  <Card title="Product facts" icon="box">
    Key details about your products or services — names, pricing tiers, core features, or launch dates — that Swell should reference accurately in campaigns.
  </Card>
  <Card title="Tone preferences" icon="comments">
    Specific language or style rules beyond your brand voice setting. For example: "We never use the word 'cheap'" or "Always refer to customers as 'members'."
  </Card>
  <Card title="Audience details" icon="users">
    Facts about who your audience is — their industry, interests, pain points, or buying patterns — that help Swell write more relevant copy.
  </Card>
  <Card title="Recurring themes" icon="rotate">
    Seasonal campaigns, standing promotions, or recurring content themes that Swell should be aware of when suggesting campaign ideas.
  </Card>
</CardGroup>

## Adding a memory

Navigate to **Workspace Settings → Memories** and type or paste the fact you want Swell to remember. Save the entry and it becomes available to Swell immediately for future drafts.

## Editing a memory

Select a memory from the list and update its text to reflect a change in your brand. For example, if a product name changes or a pricing tier is updated, edit the relevant memory so Swell always uses the current information.

## Removing a memory

Select the memory you want to delete and confirm removal. Swell will no longer reference that fact in future drafts. Removing a memory does not affect campaigns that were already generated using it.

## Correcting wrong memories

If Swell repeatedly includes incorrect information in its drafts, a memory is likely the source. To fix it:

1. Go to **Workspace Settings → Memories**.
2. Search for a memory that contains the incorrect fact.
3. Edit the memory to reflect the correct information, or delete it if the fact is no longer relevant.

<Note>
  Memories are workspace-scoped. A memory you create in one workspace is not visible to or used by Swell in any other workspace you belong to.
</Note>
