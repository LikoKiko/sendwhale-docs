SendWhale publishes release notes and known limitations at [gosendwhale.com/changelog](https://www.gosendwhale.com/changelog). Reviewing the changelog regularly helps you stay informed about new features, recent fixes, and any limitations that may affect how you use the platform — especially during private beta, when the product is evolving quickly.

## What the changelog covers

Each entry in the changelog may include:

- **Shipped features** — newly available functionality you can start using immediately
- **Bug fixes** — resolved issues that were affecting platform behavior
- **Improvements** — enhancements to existing features, performance, or reliability
- **Known limitations** — current gaps or edge cases that the team is aware of and working to address
- **Beta flags** — features that are available but still under active development and subject to change

## Private beta status

SendWhale is currently in **private beta**. During this phase:

- Features may change, be redesigned, or be removed without prior notice
- Some features may have known limitations documented in the changelog
- Behavior described in the documentation reflects the current state of the platform, but that state is actively evolving

Before relying on a feature for production or high-stakes use, check the changelog for any relevant limitations or beta flags that may affect your workflow.

## Checking for known limitations

If a feature is not behaving as you expect, the changelog is the first place to look. Known issues and temporary limitations are recorded there as they are identified. To check:

1. Go to [gosendwhale.com/changelog](https://www.gosendwhale.com/changelog).
2. Browse or search recent entries for the feature or area you are working with.
3. Look for entries marked with **Known limitation** or **Beta** flags.

Bookmark the changelog page and return to it whenever you notice unexpected behavior.

<Info>
  If you experience behavior that does not match what is described in this documentation, it may reflect a recent change that has not yet been reflected here. Check [/changelog](https://www.gosendwhale.com/changelog) first, and if the issue is not explained there, contact [support@gosendwhale.com](mailto:support@gosendwhale.com) with a description of what you observed.
</Info>
